# 학교 PC의 기존 원본과 병합

원본 소스는 확인하지 못했습니다. 기존 파일명 API와 JSON 형식의 완전 호환은 보장하지 않습니다. 이번 복구본도 이전 ZIP과 바이트 단위 동일하지 않으며 대화의 구현을 재구성한 버전입니다.

1. 학교 PC 원본·이번 복구본을 각각 전체 백업하고 실제 로그/HWP는 로컬 private 폴더에 보관합니다.
2. 기존 테스트를 원래 환경에서 먼저 실행합니다. 기존 파서/판정/주장 검증/게이트 모듈과 sev 패키지의 동작을 대응시킵니다.
3. 가상 테스트와 스키마 어댑터부터 옮깁니다. 신원 누락·세션/대상/자원/소유권·정상 요청 비교 검사를 제거하지 않습니다.
4. 세션 HMAC은 배치마다 달라 원본 가상 로그에서 다시 정규화합니다. 기존 logs.json이나 검증 결과를 통째로 덮어쓰거나 재사용하지 않습니다. 정책 manifest를 사람이 확인합니다.
5. 전체 테스트·CLI 예제·실제 Ollama 응답 검증 후 작은 단위로 병합합니다. 이미 격리된 Codex 환경에서는 기존 체크아웃을 사용하며 사용자가 요청하지 않은 worktree를 만들지 않습니다.
