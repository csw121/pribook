이 클라우드에는 cmd.exe/Windows가 없어 .cmd 더블클릭, 실제 Windows 설치, 파일 연결에 의한 브라우저 열기, 실제 Qwen 추론은 미검증입니다. Windows 관련 로직은 mocks와 Python 단위 테스트로 검증했으며, 실제 PC에서 01_setup.cmd와 가상 TXT로 추가 확인해야 합니다. 비공개 사용자 자료는 배포에 포함하지 않습니다.

# 1.1.1 인용 불일치 처리 수정

2026-10-31, Python 3.13.5. 전체 **96개 테스트 통과 / 실패 0 / 건너뜀 0**. 기존 87개 중 인용 불일치 테스트는 오류 종료 대신 격리 여부를 검사하도록 변경했고, 재요청 성공·지속 불일치·혼합 주장·공백 차이 비승인·재요청에서 사라진 주장 보존·처음 확인한 인용 보존·10조각 처리 완료·잘못된 JSON 안전 실패·CLI 저장/경고 등 9개 회귀 테스트를 추가했습니다.

원문 일치 규칙은 완화하지 않았습니다. 일치하지 않는 인용은 해당 조각을 한 번 더 분석한 뒤, 여전히 맞지 않으면 matched claims와 분리합니다. 실패 인용은 `quote_matched:false`, `TEXT_QUOTE_MISMATCH`이고 원문 위치를 부여하지 않습니다. 첫 실패 기록도 JSON에 보관합니다. 이 값들은 사람이 검토하는 미확인 내용으로만 표시됩니다. AI 요약 및 주장 자체는 계속 미검증이며 report_gate는 항상 blocked입니다.

Ollama 호출 형식과 기존 정상 응답 왕복은 모의 HTTP 서버로 확인했습니다. 실제 Qwen의 이번 자료 추론 성공은 사용자 PC에서 추가 확인해야 합니다. 사용자의 비공개 TXT는 수집하거나 업로드하지 않았습니다.

# 1.1.0 일반 TXT 검토 기능 검증

검증일: 2026-10-31(한국 시간). Python 3.13.5.

전체 **87개 테스트 통과 / 실패 0 / 건너뜀 0**. 기존 HTTP 증거 검증 70개에 일반 TXT 관련 17개를 추가했습니다. 일반 문서 읽기, UTF-8/CP949/UTF-16, 긴 한 줄 분할과 무손실 처리, 비밀 패턴 마스킹, 없는 인용 차단, 로컬 주소 강제, 미완성/잘못된 AI 응답 거부, 별도 CLI 출력, 기존 보고서 게이트 우회 차단, 모의 HTTP 서버 실제 왕복을 확인했습니다.

`ai-text`는 문서 내용의 한국어 요약과 미검증 주장/추가 확인 사항을 로컬 Qwen에 요청합니다. 실제 문서 인용은 Python이 존재 여부를 확인하지만, AI 요약이나 주장의 진실성·취약점 성공은 확인하지 않습니다. 문서 검토 결과는 항상 `unverified_text_review`, 보고서 게이트 `blocked`입니다. 원본 HTTP 증거 없이 검증된 보고서로 승격되지 않습니다.

실제 Ollama/Qwen 모델 추론은 이 클라우드에서 수행하지 않았습니다. 프로토콜과 흐름은 모의 로컬 서버로 검증했으며 실제 PC에서 `doctor`와 `ai-text`를 실행해 확인해야 합니다. Windows·한컴오피스·Open WebUI 실제 제품 연동도 미검증입니다.
