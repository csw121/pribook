## 실제 확인한 범위

가상 로그 6개 정규화, 사실 주장 24개 검증, Markdown/HTML/DOCX 초안 생성 및 DOCX 구조 재분석. 동일 정상 DB 오류는 unknown/blocked/종료 2로 확인했습니다. Ollama는 **모의 로컬 HTTP 서버**로 API 형식과 옵션을 시험했으며 실제 Qwen 모델 추론이 아닙니다.

Windows 11, 실제 Ollama/Qwen·두 GPU의 VRAM, Open WebUI 화면 연동, 한컴오피스/Word에서 DOCX 열기·레이아웃은 로컬 추가 검증이 필요합니다. HWP 직접 읽기/생성·PDF 파싱·최종 승인 전자서명은 미구현입니다.

## 파일 전달

작업 환경 내부 경로는 영구적인 다운로드 주소가 아닙니다. 이 복구본 소스와 ZIP을 GitHub에 업로드하면 클라우드 환경과 별개로 받을 수 있습니다. 원격 업로드 전 사용자에게 저장 위치와 변경 범위를 확인합니다. 실제 증거/개인정보/venv/결과물은 업로드 대상에서 제외하고 가상 예제만 포함합니다.
